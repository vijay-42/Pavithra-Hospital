# Pavithra-Hospital

Website for Pavithra Hospital, 12 Erikarai Road, Pennagaram, Tamil Nadu 636810.

Built with Next.js. English and Tamil.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 (add `?lang=ta` for Tamil).

## Editing

- Hospital details (phone, hours, WhatsApp, rating): `lib/site.ts`
- All text, English and Tamil: `lib/content.ts`
- Photos: `public/images/` — replace with the hospital's own photos using the same file names
